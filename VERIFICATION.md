# Результаты проверки

Проверка выполнена 10 ноября 2026 года в Chromium через Playwright. Приложение запускалось на локальном тестовом HTTP-сервере.

## Адаптивность

Все 13 HTML-страниц проверены на 360, 430, 768, 1024 и 1440 px: **65 проверок** на проект. На каждой странице ровно один h1, есть viewport, изображения загружаются, ширина документа не превышает ширину окна. Таблица прокручивается внутри собственного контейнера.

Машинные данные находятся в `screenshots/verification.json`. В `screenshots/` также сохранены полноразмерные снимки главной и каталога на 360 и 1440 px.

## Сценарии

- Раскрытие и сворачивание мобильного меню.
- Открытие быстрой заявки с предвыбранным iPhone.
- Переходы Tab между полями модального окна; Escape закрывает окно. При обходе элементов браузер может временно переводить фокус в собственную панель.
- Выбор любого из трёх брендов оставляет по три карточки. Фильтр 64 ГБ оставляет только Galaxy S8.
- Цена до 1 ₽ показывает пустое состояние; сброс возвращает девять моделей.
- Сортировка по возрастанию цены ставит Redmi 13C первым.
- Переход в заявку и открытие модального окна проверены для всех девяти моделей: выбор и стоимость соответствуют товару. На всех страницах товара КР3 удалена указанная надпись.
- Валидная заявка показывает сообщение о демонстрации; сетевой отправки нет.
- Валидное сообщение обратной связи показывает собственный результат.
- Не обнаружено ошибок JavaScript в проверенных сценариях.
- Статически проверены уникальность id, связи label/полей, наличие name и существование локальных ссылок/ресурсов.
- Синтаксис JS проверен командой `node --check js/main.js`.

## Как повторить

1. Запустите `python -m http.server 8000` в корне проекта.
2. Откройте `http://localhost:8000/index.html` в Chrome.
3. DevTools → Lighthouse → Accessibility → Analyze page load.
4. Повторите для catalog.html и order.html и сохраните отчёты.
5. В DevTools → Device Toolbar по очереди задайте пять указанных ширин, проверьте меню, формы и таблицу.

Общий предпросмотр среды Sites не запустился из-за тайм-аута relay. Это не помешало отдельным автоматическим проверкам приложения в локальном Chromium и запуску Lighthouse. Веб-публикация не выполнялась.
