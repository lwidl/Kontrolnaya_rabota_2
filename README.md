Учебный многостраничный магазин смартфонов. Предметная область, название SmartLine, три исходные фотографии и преимущества сохранены из предоставленного `KR1.rar`. Каталог расширен до девяти моделей; добавлены фотографии, индивидуальные характеристики и цены. Данные товаров условные: это демонстрационный каталог, а не актуальные спецификации производителей. Контакты также учебные.

## Запуск

1. Распакуйте проект.
2. Откройте `index.html` в обычном браузере. Все стили, изображения и скрипты находятся локально; интернет не нужен.
3. Рекомендуемый вариант для проверки Lighthouse: в папке проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

Никакой сборки, Node.js или установки npm-пакетов для работы сайта не требуется. Для запуска через Python он должен быть установлен. Некоторые корпоративные браузеры могут запрещать открытие локальных файлов — используйте локальный HTTP-сервер.

## Модели в каталоге

- **iPhone**: iPhone 17 Pro, iPhone 13 Pro, iPhone X.
- **Samsung**: Samsung Galaxy A54, Samsung Galaxy S10, Samsung Galaxy S8.
- **Redmi**: Redmi Note 11 Pro, Redmi Note 13, Redmi 13C.

В каталоге девять карточек, по три на бренд. На главной показаны три популярные модели — по одной от каждого бренда. Все девять моделей доступны в форме и быстрой заявке. Источники фотографий перечислены в `ASSETS.md`.

## Страницы и сценарии

- С главной можно открыть каталог или быструю заявку на iPhone.
- У каждого товара есть отдельная страница и кнопка заказа.
- Ссылка `order.html?model=redmi` автоматически выбирает Redmi и обновляет стоимость.
- В каталоге работают комбинированные фильтры бренда, памяти и максимальной цены. Можно сортировать по цене, сбросить фильтры и увидеть сообщение, если нет результатов.
- В заявке есть имя, e-mail, телефон, модель, дата связи, способ получения, комментарий и согласие. Валидация основана на HTML `required`, `type`, `pattern`, `minlength` и `maxlength`.
- Телефон вводится как 10 цифр после визуального префикса +7. Подсказка связана с полем через `aria-describedby`.
- Форма обратной связи имеет отдельный набор полей и своё сообщение о результате.
- Формы демонстрационные: данные проверяются только в браузере, никуда не отправляются и не сохраняются. Результат явно сообщает об этом. Бэкенд и приём оплаты в работу не входят.

## Фреймворк и способ подключения

Bootstrap **5.3.8 подключён локально**, без CDN:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js" defer></script>
```

Оригинальная лицензия MIT находится в `vendor/bootstrap/LICENSE`. CSS и JS получены из официального дистрибутива Bootstrap 5.3.8 через jsDelivr. Собственный `custom.css` идёт после Bootstrap и задаёт цвета, hero, размеры изображений и фирменное оформление. Он не копирует реализацию сетки или компонентов Bootstrap.

Проект подготовлен как отдельный локальный Git-репозиторий. Публикация в GitHub и СДО не выполнялась: в исходных материалах нет данных вашей учётной записи. В архиве `repository.bundle` сохранена локальная история. Чтобы восстановить репозиторий с ней, выполните из распакованной папки:

```bash
git clone repository.bundle ../smartline-repository
cd ../smartline-repository
```

Создайте в своём GitHub отдельный пустой репозиторий с именем проекта, затем, подставив свой URL:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_ПРОЕКТА.git
git push -u origin main
```

Если история не нужна для переноса, можно загрузить исходные файлы через GitHub → Add file → Upload files. При желании включите Settings → Pages → Deploy from a branch → main → /(root). После публикации впишите настоящие ссылки ниже.
