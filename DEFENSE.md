# Пояснение для защиты SmartLine

Откройте сайт, затем покажите код в редакторе. Этот файл помогает разобраться в реализации; перед защитой проверьте, что можете объяснить её своими словами.

1. `index.html` — главная. Семантические разделы, преимущества, три модели и FAQ.
2. `catalog.html` — девять карточек с `data-brand`, `data-memory`, `data-price`. В `js/main.js` значения фильтров сравниваются с этими атрибутами. Несовпадающие карточки получают `hidden`; сортировка меняет порядок узлов DOM.
3. Страницы `product*.html` статические: содержимое доступно без JS. Таблица имеет `caption`, заголовки колонок и строк со `scope`.
4. Кнопка заказа ведёт на `order.html?model=...`. `URLSearchParams` читает модель, проверяет её по известному списку, выбирает option и обновляет сводку через `textContent`.
5. У форм есть `label`, `name`, типы полей и ограничения HTML. `submit` отменяет сетевую отправку через `preventDefault`, проверяет валидность и показывает честное сообщение о демонстрации через `role="status"`. Данные не сохраняются.
6. `picture` сначала предлагает WebP двух размеров через `srcset`; `sizes` сообщает браузеру ожидаемую ширину картинки. `img` даёт запасной JPEG, alt и размеры. `loading="lazy"` отложен для карточек, hero имеет высокий приоритет.
7. Skip-link позволяет сразу перейти к основному содержимому, обходя меню. Фокус виден при управлении с клавиатуры.

## Что показать в браузере

- Каталог: Redmi → найдены три модели; цена до 1 ₽ → пустой результат; «Сбросить» → девять моделей; сортировка по возрастанию цены → сначала Redmi 13C.
- Страница товара → «Оформить заказ» → выбрана нужная модель и показана цена.
- Пустая форма не проходит встроенную проверку браузера. Корректная форма показывает сообщение без отправки.
- Мобильное меню, открытие быстрой заявки, Tab/Shift+Tab, Escape.
- Ширины 360, 430, 768, 1024 и 1440 px в DevTools.
- Отчёты `lighthouse/index-accessibility.report.html`, `catalog-accessibility.report.html`, `order-accessibility.report.html`.

## Bootstrap

`container` ограничивает и центрирует содержимое. `row` содержит колонки и задаёт gutters, `col-12` занимает всю 12-колоночную сетку. `col-md-6` даёт две колонки от 768 px, `col-lg-3` — четверть строки от 992 px. `g-4` задаёт промежутки по обеим осям. Мобильное меню, modal и accordion работают через Bootstrap JS Bundle и атрибуты `data-bs-*`. `custom.css` подключён позже библиотеки, поэтому фирменные значения переопределяют стандартные. Локальное подключение позволяет работать без CDN и интернета.
